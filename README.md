# Timeline Sort Game

A simple browser-based timeline game for students.

## How to use it

1. Open `index.html` in a web browser.
2. Type or paste timeline events into the text box, one event per line, in the
   correct order.
3. Select **Scramble events**.
4. Students drag the events or use **Move up** / **Move down** to place them in
   the correct order.
5. Select **Check my timeline** to see whether the order is correct.

Blank lines are ignored. Use **Load example** if you want to try the game before
adding your own timeline.
